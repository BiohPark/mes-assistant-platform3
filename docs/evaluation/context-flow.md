# 기능 평가 — 파일·대화 컨텍스트 흐름

설계: [../fusion-design.md](../fusion-design.md) §7 · 실행: `npm run test:e2e` (`e2e/context-flow.spec.ts`)

- 모든 평가는 **가상 자료 + 가짜 OpenWebUI**(`e2e/support/fakeOpenWebUI.ts`)로 한다. 가로챈 요청 본문 = "AI가 실제로 받은 것"으로 판정한다.
- 실제 OpenWebUI 연결·파일 이해 품질은 이 평가 범위가 아니다 → [real-env-verification.md](real-env-verification.md)
- 스크린샷·trace는 저장소 밖(`%TEMP%/mes-hub-e2e`)에 남는다.

## E1 기준선 (수정 전, `docs/fusion-design` 브랜치 코드 = master `6389190` 기능 코드)

실행일 2026-09-26 · Edge + Playwright 1.63 · 1280×800

| # | 시나리오 | 기대 | 결과 | 관찰 |
|---|---|---|---|---|
| S1 | 컴포저로 첨부 후 두 번째 턴 | 두 번째 요청에도 첨부 본문 포함 | **실패** | 첫 요청에만 포함, 두 번째 요청의 system 프롬프트에 없음 |
| S2 | SR 접수 대화에서 첨부 후 전송 | 그 메시지 요청에 첨부 포함 | **실패** | 첫 요청에 첨부 없음(전송 시점의 SR 파일 목록이 업로드 전 값) |
| S3 | 기본 이름으로 산출물 2회 저장 | 같은 파일 v1 → v2 | **실패** | 이름이 `…_v1.md`, `…_v2.md`로 달라 둘 다 v1 (버전 체인 없음) |
| S4 | 태그 공유 자료 ☑ 먼저·★ 나중 선택 후 전송 | 주 입력이 참고보다 먼저 | 통과 | 인라인 모드 system 프롬프트에서 주 입력이 먼저 |
| S5 | OpenWebUI 첨부 방식 | 처리 상태 확인 후 전송 · `files[0]` = 주 입력 · 업로드 이름에 `(v2)` | **실패** | 업로드 이름이 원본 이름 그대로, 처리 상태 조회 없음 |
| S6 | 프롬프트 생성 중 예외(파일 본문 읽기 실패) | 답변이 오류로 끝나고 입력창 사용 가능 | **실패** | 답변 자리표시가 `streaming`으로 남아 입력창이 "중지" 상태로 잠김 |
| S7 | 두 탭에서 거의 동시에 전송 | 진행 중 요청 1건 | **실패** | 요청 2건이 동시에 나감 |
| S8 | Mock 응답의 자료 인지 | 매 턴 "사용한 자료"(등급·버전) 표시 | **실패** | 일부 시나리오만 파일 이름을 한 줄로 언급, 등급·버전 없음 |

요약: 8개 중 1개 통과. 코드 추적으로 예상한 결함([fusion-design.md](../fusion-design.md) §2)이 브라우저에서 모두 재현됐다.

### E6 UX 점검 — 개발자 점검 (현업 시험 전)

실제 사용자 시험이 아니라 개발자가 브라우저에서 과업을 따라 해 본 결과다. 현업 시험 절차는 [ux-test-script.md](ux-test-script.md).

**화면 점검**: 1280px·375px에서 10개 라우트(홈·칸반·새 대화·대화 2건·SR 접수·SR 관리·에이전트 관리·리포트·설정) 가로 넘침 0, 콘솔 오류 0. 375px에서 트레이는 접힌 상태로 시작(한도 초과 시 자동 펼침).

| 과업 | 이전 | 이후 |
|---|---|---|
| 같은 태그 대화의 결과를 AI 입력으로 쓰기 | 불가능 — 답변을 산출물로 저장 → 다른 대화로 이동 → 자료함에서 체크 (화면 이동 2회) | 자료 탭 "같은 태그 대화"에서 체크 1회 |
| 보내기 전에 무엇이 가는지 확인 | 불가능 (전송 후 JSON 다운로드뿐) | 입력창 위 트레이에 항목·전달 방식·크기 (데스크톱 0회, 모바일 1회 탭) |
| 보낸 뒤 무엇이 갔는지 확인 | JSON 다운로드 | 답변 아래 "사용한 자료" → 앱 안 전송 기록 (1회) |
| 파일 전달 실패 복구 | 조용히 본문 대체(바이너리는 이름만) — 실패를 알기 어려움 | 실패 답변 자리에서 1회 (다시 시도 / 빼고 다시 / 텍스트로 보내기) |
| SR 결과를 파일과 함께 공유 (SR 관리 화면) | 파일 후보가 비어 공유 불가 | 연결 대화의 산출물이 후보로 표시 |
